# 다독 서가 (多読) — 일본어 다독 앱

문법 설명 없이, 이해되는 만큼만 읽으면서 일본어를 자연스럽게 익히는 앱입니다.
크라센(Krashen)의 '이해 가능한 입력' 이론을 바탕으로 만들었습니다.

**바로 사용하기: https://taehunyeoul-dot.github.io/dokudo/**

## 사용법

1. 위 주소를 폰이나 컴퓨터 브라우저로 엽니다.
2. 일본어가 처음이라면 갈색 글자책 「ひらがな」부터 — 글자를 탭하면 소리가 나요.
3. 글자를 뗐으면 초록색 그림책부터 읽으세요. 모르는 단어는 탭하면 뜻이 보입니다.
4. 문장 앞 ▶ 버튼을 누르면 읽어줍니다.

### 폰 홈 화면에 추가하기 (앱처럼 쓰기)

- **아이폰(사파리)**: 공유 버튼 → "홈 화면에 추가"
- **안드로이드(크롬)**: 메뉴(⋮) → "홈 화면에 추가"

## 알아두기

- 읽은 기록(완독 표시, 단어 탭)은 **각자 자기 기기 브라우저에만** 저장됩니다. 서버·계정이 없어요.
- 모든 일본어 지문은 이 앱을 위해 새로 창작한 원본입니다.
